# jude-portfolio

Static portfolio website. The GitHub Actions workflow deploys the site to GitHub Pages when changes are pushed to `main`.

## Publish

1. Create a public GitHub repository and upload the contents of this folder to its root.
2. In the repository, open **Settings > Pages** and set the source to **GitHub Actions**.
3. Push to `main` or run the **Deploy static site to GitHub Pages** workflow from the Actions tab.

The published address will be `https://<your-username>.github.io/<repository-name>/`.

Add `assets/well-of-life.jpg` and `assets/digital-logic.jpg` before publishing if you want those project images to appear; those files are not currently in this folder.
